# Licensing

[Buy Premium](https://diligiteiustitiam.world/nuncsonat/subscribe/). There is no trial. Monthly, annual, and perpetual licenses are paid at checkout. Prices exclude tax. Stripe adds tax.

## Activate

1. After checkout, the license key arrives by email.
2. On the Mac, open Settings → Premium.
3. Paste the key and tap **Activate**.

Premium unlocks immediately. You do not relaunch the app.

The same panel is where **Enter license key…** in the upgrade prompt sends you. **Upgrade to Premium…** opens the checkout page.

## Three Macs

One key works on up to 3 Macs. Activate it on each Mac with the same steps.

To move the key, open Settings → Premium on the Mac you are retiring and tap **Deactivate this Mac**. That Mac returns to Free, and the key can be activated on another one.

If activation says the device limit is reached, deactivate a Mac you no longer use, then activate again.

## Billing

Payment method, invoices, switching monthly and annual, and canceling a subscription are in the Stripe customer portal linked from the checkout site. A perpetual license has no renewal to cancel.

License and billing questions go to [developer@diligiteiustitiam.world](mailto:developer@diligiteiustitiam.world), not to a public GitHub issue.
